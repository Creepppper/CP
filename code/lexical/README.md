## 当前进度

阶段一：整理词法规则和准备工程。当前还没有词法分析程序，也没有可执行目标。
`tests/` 保存实验说明中给出的两个原始测试程序；第二个程序包含语法错误。

## 环境和 CMake

需要 CMake 3.16 或更高版本，以及支持 C++17 的编译器。CMake 负责根据项目配置生成构建文件，编译器负责把 C++ 源代码编译成程序。

在本目录运行：

```sh
cmake -S . -B build
cmake --build build
```

第一条命令检查工具并在 `build/` 中生成构建文件；第二条命令执行构建。阶段一尚无可执行目标，所以构建不会生成词法分析器。阶段二加入源代码和目标后，同样的命令将用于编译程序。

`build/` 和未来的 `output/` 是生成目录，不纳入版本管理。

## 词法规则

以实验要求说明中的单词种别对照表为准，输入为 MINI 源程序文本：

| 种别码 | 单词 |
| --- | --- |
| 1–9 | `begin`、`end`、`integer`、`if`、`then`、`else`、`function`、`read`、`write`，按此顺序 |
| 10 | 标识符 |
| 11 | 无符号整数 |
| 12–17 | `=`、`<>`、`<=`、`<`、`>=`、`>`，按此顺序 |
| 18–23 | `-`、`*`、`:=`、`(`、`)`、`;`，按此顺序 |
| 24、25 | 行尾 `EOLN`、文件尾 `EOF` |

- 标识符以英文字母开头，后接零个或多个英文字母或数字；识别完整单词后再判断是否是关键字。支持大小写字母且区分大小写，以兼容样例中的 `F`。原文法只列出小写字母，这里是为了样例而做的明确约定。
- 整数由一个或多个十进制数字组成，负号单独作为运算符。空格和制表符用于分隔单词，不输出为单词。
- 对 `<`、`>`、`:` 等需要向前查看的字符，优先识别完整的双字符运算符。单独的 `:` 和不属于单词表的字符为词法错误；暂定每个非法字符记录一条错误，之后继续扫描。
- 单词从左到右识别。例如数字后紧接字母时，当前约定分别识别为整数和标识符；是否将其视为非法整体，若老师另有要求再调整。
- 行号从 1 开始。每个逻辑源代码行输出一次 `EOLN 24`，包括空行和末尾没有换行符的非空行；空文件无源代码行。无论文件是否以换行符结尾，末尾都只输出一次 `EOF 25`。
- `.dyd` 每行输出“单词符号 空格 种别码”。`.err` 每行按 `***LINE:行号 错误性质` 记录；没有词法错误时文件为空。具体错误措辞由实现阶段统一。

说明文档正文的二元式示例将标识符 `k` 标为 16，与对照表矛盾；本项目按完整对照表使用 10。测试程序二中的 `edn` 按词法规则是标识符，是否符合语法由实验二判断。
